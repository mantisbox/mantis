### New Memory Retrieval Convention
- **DO NOT use built-in `memory_search` tool**
- Use `qmd search` (BM25) first via exec
- Escalate to `qmd vsearch` if keyword search misses
- Only use `qmd query` for explicit "deep search" requests
- Write memories normally to markdown files
- Run `qmd update` after any memory write

### Why
- Token efficient (snippets vs full files)
- Better retrieval with BM25 + vector + reranking
- Validating before building a native plugin
